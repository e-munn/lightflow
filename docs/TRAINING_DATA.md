# Training-data sources — research in progress (2026-08-25)

Goal (see ML_ROADMAP.md): imitation-learn a small model (mel window → per-frame brightness / stem focus / effect) from the deterministic Director, then fine-tune on human signal. This doc collects possible data sources. Status: 1 of 6 source families deeply researched (rhythm games — complete, verified); the rest are queued below.

## 0. Data we already own (no research needed)

- **The deterministic teacher** — run Director + attention over any analyzed song → unlimited (frame → label) pairs. The roadmap's "cheat code"; needs only a legal audio corpus (family 1).
- **Scout files** (`*_scout.json`) — Claude-generated moments/section annotations for ~8 songs; grows with use.
- **Recorded shows** (`*_show.json` via the old MIDI recorder) — small but genuinely human.
- **Phase-4 correction capture** (planned) — log (song, t, predicted, user_override) during playback.

## 1. Rhythm-game charts & MIR annotations — RESEARCHED, verified Aug 2026

Best human-annotation source family found. Key findings:

| Source | Signal | Volume | Access | Legal |
|---|---|---|---|---|
| **Beat Saber (BeatSaver)** | Human-authored **lighting event tracks** in maps: v2 `_events` / v3 `basicBeatmapEvents` — beat-time, light group (0–43), value (Off/Static/Flash/Fade × color), `floatValue` brightness | ~343k maps (id `53df4` hex, Aug 2026) | `api.beatsaver.com` (swagger /docs; per-map zip incl. ogg audio); bulk metadata: GitHub `andruzzzhka/BeatSaberScrappedData` (updated daily) | Community maps, no formal license; audio in zips is copyrighted — keep local, never redistribute. **Filter auto-generated lights** (Lolighter/LightMap): use ranked/curated flags, event-entropy thresholds |
| **osu! beatmaps** | `[TimingPoints]` beat grid + **kiai flag** (human "high-energy section" bit) + note density | ~150k+ ranked; monthly dump ~1.35 GB | **Official dumps: `https://data.ppy.sh/YYYY_MM_01_osu_files.tar.bz2`** (.osu files, no audio). Audio mirrors: catboy.best, beatconnect.io, nerinyan.moe (chimu/bloodcat dead) | Dumps officially published; kiai = cheapest at-scale energy label |
| **Rock Band VENUE tracks** | Professional lighting direction as MIDI text events: `[lighting (strobe_fast/blackout_fast/flare_slow/verse/chorus/…)]` + `[first]/[prev]/[next]` keyframes — vocabulary maps ~1:1 onto our effect enum | ~2k official (Harmonix-authored); ~140k customs on RhythmVerse (but customs' venues often auto-generated by Magma/venuegen — prefer official) | RhythmVerse.co (no bulk API); format docs: docs.c3universe.com/rbndocs (http only) | Fan MIDI over copyrighted audio; pair with purchased copies |
| **Harmonix Set** | Beats/downbeats/**functional sections** for 912 pop/EDM tracks, JAMS + ~1.2 GB precomputed mel-spectrograms | 912 | GitHub `urinieto/harmonixset` | **Annotations MIT**; audio via YouTube refs |
| **SALAMI / SALAMI-IA** | Expert structure annotations | 2.2k annotations; ~450 with free IA audio | GitHub `DDMAL/salami-data-public` | **CC0** |
| **Ballroom** | Beat/bar annotations + freely downloadable audio | 698 clips | mtg.upf.edu + GitHub `CPJKU/BallroomAnnotations` | Open |
| Skip | Rocksmith showlights (auto-gen), StepMania (osu! dominates), Clone Hero (weak) | | | |

**Pairing strategy:** annotations are safe (official dumps / MIT / CC0 / distributed without audio); audio is always the constraint — keep it local for feature extraction, never redistribute; ship only the model.

**Tiering:** 1) Beat Saber lighting events (closest analogue to our output space: effect class + brightness per beat). 2) osu! kiai at scale (energy-section pretraining). 3) RB official VENUE as gold fine-tune set. 4) Harmonix/SALAMI/Ballroom for clean beat/section heads.
